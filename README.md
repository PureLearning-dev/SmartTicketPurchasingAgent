# 12306 购票智能体

## 任务安排

研究内容：

（1）基于12306旅客购票数据，融合短期行为、长期偏好以及节假日与日常出行场景，构建可持续更新的旅客出行偏好画像模型，动态刻画出行时间、席别、常用发到站组合和价格敏感度。

（2）研究自然语言意图识别、上下文状态维护和业务指令映射技术，构建支持长短期记忆的“业务—模型”桥接框架，实现购票业务中多模型、多工具的自动调度与可控执行。

（3）融合旅客偏好画像、铁路领域知识库和多智能体协同技术，提供经济优先、速度优先和便捷优先等铁路出行方案；研究铁、空、公、水等交通方式的联程方案生成及语音、文本交互式购票智能体，推动铁路客运服务由被动响应向主动服务转变。

考核指标：

（1）12306购票智能体客户满意度超过90%，智能购票方案推荐采纳率超过70%。

（2）形成1个铁路客运票务服务高质量数据集。

（3）构建意图识别大模型和联程方案生成大模型各1个。

（4）形成12306智能体技术条件、接口规范、数据标准及相关管理办法建议稿。
